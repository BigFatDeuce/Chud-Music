**Stability with big libraries**
The Albums and Artists views now draw only what is on screen, with small copies of the covers. A library of thousands of albums no longer eats memory — this is what crashed the window on Linux when clearing an artist filter (the × next to the artist's name).

A bug in one page no longer takes the whole window down: the page shows the error with a "Try again" button, while the sidebar, the tabs and playback keep working.

**Scan the library by hand**
Library › … › Scan the library. The catch-up scan at start now waits 30 seconds (so the app is up and playing first), and is skipped if you scan by hand meanwhile.

**Find missing covers**
Library › … › Find missing covers looks up, on YouTube Music, the cover of every album or song of your library that has none. When the album is not found, the artist's picture is used; when nothing is found, a "?" is shown. "Remove found covers", just below, deletes all of them.
These pictures stay in Chud Music's own cache folder: nothing is ever written into your music folders, and your files are not modified.

**More download formats**
- Windows: the installer (updates itself), a portable `.exe` that runs without installing, and a `.zip`.
- Linux: the AppImage (updates itself), `.deb` (Debian, Ubuntu, Mint…), `.rpm` (Fedora, openSUSE…) and `.tar.gz`.

The portable, zip, deb, rpm and tar.gz versions tell you when a new version is out and open this page; they do not update themselves.

**Fixes**
- Quitting while recording the radio now saves the whole recording.
- A recording folder that cannot be created (removed drive…) shows an error instead of failing silently.
- A library scan that fails (disk full, drive removed during the scan) stops cleanly instead of staying "in progress".

`ffmpeg-9.0.2.tar.xz`: the exact source code of the bundled FFmpeg (LGPL). Not needed to use Chud Music.
