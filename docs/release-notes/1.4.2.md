**Chud Music 1.4.2**

Signed updates, whole lyric lines in small windows, and three reliability fixes.

**Security**
- *Signed updates*: every update installed from inside the app now carries a signature made with Chud Music's own key, and the app checks it after the download, before offering *Restart and install*. An installer without that signature, or signed with another key, is never installed: the app offers the release page instead. This protects you from now on, starting with the update after this one.

**Fixes**
- *Synced lyrics*: in a small window, the lyrics above the player controls were cut with "…". Lines now wrap; when there is not enough room, the previous and next lines give way and the current line gets smaller, so it is always shown in full.
- *Duplicates*: two entries of the same track are now always found, even when they were saved with different titles or artists (for example before the track's tags changed).
- *Cover thumbnails*: removing found covers no longer lets a thumbnail that was still waiting to be made come back right after the cleanup.
- *Cover images*: a failed write (a full disk, for example) is now reported instead of being hidden when an incomplete image from an older version was already there.

`ffmpeg-9.0.2.tar.xz`: the exact source code of the bundled FFmpeg (LGPL). Not needed to use Chud Music.
