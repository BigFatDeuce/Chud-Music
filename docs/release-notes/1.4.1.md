**Chud Music 1.4.1**

A reliability and security update: Electron (Chromium) security fixes, more careful duplicate detection, sturdier cover images, and links read the same way everywhere. Chud Music is now open source (GPL-3.0-or-later).

**Fixes**
- *Duplicates*: two versions of a song are only grouped when their durations are within 3 s of each other. Before, a chain of versions (3:00, 3:03, 3:06) or a track of unknown duration could group songs that were not the same, and a removed version could end up with no close copy kept.
- *Cover images*: covers and their thumbnails are now written in one piece. An interrupted write (the PC switched off, the app closed during a scan) could leave a broken image that stayed broken; it can no longer happen. If a found cover is already broken, *Remove found covers* in the Library menu clears it.
- *Playlist covers*: the small copies of a playlist image are deleted with it instead of staying on disk.
- *Links*: a YouTube link that names two different videos (or two playlists) is no longer read as a link; the same rule as Chud Music More, checked against a shared set of 49 test links. *M3U import* now reads each line with the same rules: a line pointing to another site is no longer taken for a YouTube track, and shared links with extra parameters are recognised.
- Seeking in local files: unusual byte ranges requested by the player are now answered correctly instead of failing.

**Under the hood**
- Electron 45.4.1 (Chromium security fixes).
- The source code is published on GitHub under GPL-3.0-or-later.
