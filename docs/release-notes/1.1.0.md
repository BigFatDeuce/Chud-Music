**Chud Music 1.1.0**

Playlists get sorting, duplicate finding and link import; the Home page can be trimmed down; big libraries and the radio display better.

**Playlists**
- Sort a playlist by title, artist, album or duration by clicking the column, as in the library. A third click brings back the playlist's own order; sorting never changes the saved playlist.
- *Find duplicates…* (playlist *…* menu): finds tracks that appear more than once (the same track, or the same title and artist with nearly the same length, such as a local file and its YouTube Music twin), shows them and asks before removing them. The first one of each is kept.
- An empty playlist now has a field to paste a YouTube Music, YouTube or Spotify link (playlist, album or track): its tracks are found on YouTube Music and added. Other services (Deezer, Apple Music…) are not supported.

**Home**
- Right-click a track in *Recently played* or *Recently added* › *Remove from…* takes it out of that list (on Home and in the Library views). Your listening history, statistics and library are untouched; a track played or added again comes back.
- Settings › Home: show or hide each section (Recently played, Random, Recently added, Shortcuts, Keyboard).
- The clock is bigger and vertically centred on the right, in every skin. In a narrow window it moves above the text instead of disappearing.

**Library**
- Very large libraries: the track number column was too narrow for 6-digit numbers, so the last track of a 142,527-track library read "42527". The column now widens with the number of tracks.

**Radio**
- The *Live* badge no longer flickers to "-0:10" and back while you listen live. It only shows a delay when you go back in time or pause.

`ffmpeg-9.0.2.tar.xz`: the exact source code of the bundled FFmpeg (LGPL). Not needed to use Chud Music.
