**Chud Music speaks 10 languages**
French, English, Spanish, German, Italian, Portuguese (Brazil), Russian, Japanese, Simplified Chinese and Korean. By default Chud Music follows your system language (English if yours is not offered yet); you can pick another one in Settings › Language. Dates, numbers, weekday names and country names follow the chosen language too. Chinese, Japanese and Korean use bundled Noto Sans fonts, so they display correctly even on Linux systems without those fonts. Right-to-left languages are not offered: the layout is not built for them yet.

**Signal skin**
- The seek bar became a broadcast tape: tick marks, an RGB-split fill, a phosphor playhead beam and, while playing, a light scan running along it with an occasional signal tear (Effects: Full).
- Tabs that are not open are now clearly visible: a raised graphite chip with readable text instead of dark text on a dark background.
- The blacks of the interface are a bit lighter.

`ffmpeg-9.0.2.tar.xz`: the exact source code of the bundled FFmpeg (LGPL). Not needed to use Chud Music.
