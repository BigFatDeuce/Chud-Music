First public release of Chud Music, for **Windows** (10 and 11, 64-bit) and **Linux** (AppImage x86_64).

**What's inside**
- A library of your folders (subfolders included), tabs, playlists, queue, drag and drop.
- All common formats, plus ALAC, WMA, AIFF, WavPack, AC3, TTA… thanks to FFmpeg (included).
- YouTube Music without an account, through the official player, with an optional ad blocker.
- Radio from all over the world (Radio Browser), favorites.
- Synced lyrics (LRCLIB).
- MilkDrop visualizer, 10-band equalizer, listening statistics, mini player.
- Five skins: Chud Nocturne, Cassette 98, Aqua Glow, Platine and Signal.

The interface is in French for now.

**Install**
- Windows: `Chud-Music-Setup-0.1.0.exe`. The installer is not code-signed: if SmartScreen shows up, click "More info", then "Run anyway".
- Linux: `Chud-Music-0.1.0-x86_64.AppImage`, make it executable (`chmod +x`) and run it.

`ffmpeg-9.0.2.tar.xz`: the exact source code of the bundled FFmpeg (LGPL), for anyone who wants to read or rebuild it. Not needed to use Chud Music.
